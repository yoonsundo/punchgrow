# Security policy / 보안 정책

[한국어](#한국어) · [English](#english)

## 한국어

### 지원 범위

현재 릴리스와 `main` 브랜치에서 재현되는 보안·개인정보 문제를 우선 확인합니다. 오래된 버전에서만 발생한다면 최신 버전에서도 재현되는지 함께 알려 주세요.

### 비공개 제보

보안 또는 개인정보 문제를 공개 이슈에 올리지 마세요. [GitHub 비공개 취약점 제보](https://github.com/yoonsundo/punchgrow/security/advisories/new)를 사용해 주세요. GitHub가 양식을 표시하지 않더라도 공개 댓글에 취약점 세부 정보를 남기지 마세요.

제보에는 가능한 범위에서 다음을 포함해 주세요.

- 영향받는 버전 또는 커밋
- 개인정보를 제거한 재현 순서와 최소 증거
- 예상 영향과 알고 있는 완화 방법

수신 확인 후 재현 가능 여부, 영향 범위, 수정·공개 일정을 비공개 채널에서 조율합니다. 보안 수정이 공개되기 전에는 세부 내용을 공개하지 말아 주세요.

## English

### Supported scope

Security and privacy issues reproducible on the current release or `main` branch receive priority. If a finding affects only an older version, please also note whether it reproduces on the latest version.

### Private reporting

Do not open a public issue for a security or privacy finding. Use [GitHub private vulnerability reporting](https://github.com/yoonsundo/punchgrow/security/advisories/new). If GitHub does not show the form, do not post vulnerability details in public comments.

Include, when possible:

- the affected version or commit;
- minimal reproduction steps and evidence with private data removed;
- the expected impact and any known mitigation.

After acknowledgement, reproduction, impact, remediation, and coordinated disclosure will be discussed privately. Please keep details private until a fix is published.
