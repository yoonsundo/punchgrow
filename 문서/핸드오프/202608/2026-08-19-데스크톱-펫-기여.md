# 2026-08-19 데스크톱 펫 기여 HANDOFF

## 범위

- `yoonsundo/punchgrow`의 깨끗한 `main`에서 `agent/desktop-pet` 브랜치를 만들었다.
- 사용자 포크 `2001056/punchgrow`를 `origin`, 원본 저장소를 `upstream`으로 연결했다.
- 대표 크리처를 배경 없는 작은 데스크톱 펫으로 표시하는 macOS 기능만 포함한다.
- 토큰 수집 기준선 수정, 리소스 번들 우회, 기존 로컬 작업 폴더의 다른 변경은 포함하지 않는다.

## 구현

- `DesktopPet.swift`: 투명·비활성 `NSPanel`, 모든 Space와 전체 화면 보조 영역 참여, 드래그, 위치 복원·화면 안 보정, 표시 토글, 움직임 줄이기를 구현했다.
- 대표 크리처와 고정 표시 모습을 우선하고 대표가 없을 때만 현재 크리처를 사용한다.
- Vision 전경 마스크로 카드 배경을 제거하며, 실패 시 가장자리 연결 배경만 제거하는 로컬 fallback을 사용한다.
- `Data & Settings`에 표시 토글을 추가하고 앱 시작·종료 수명주기에 controller를 연결했다.
- PRD, 결정 기록, 와이어프레임, 한·영 사용 설명서와 macOS README를 갱신했다.
