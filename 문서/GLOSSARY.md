# 용어집 (초보자용)

개발 중 등장한 용어를 한 곳에 모아둡니다. 여기 있는 용어는 대화에서 다시 처음부터 설명하지 않고, 이 문서를 참고합니다.

| 용어 | 뜻 |
|---|---|
| React Native | 하나의 코드로 iOS·안드로이드 앱을 동시에 만들 수 있게 해주는 프레임워크. JavaScript/TypeScript로 작성한다. |
| Expo | React Native 개발을 쉽게 만들어주는 도구 모음. 복잡한 초기 설정 없이 바로 앱을 실행/테스트할 수 있게 해준다. |
| Expo Go | 개발 중인 앱을 실제 폰에서 바로 확인할 수 있게 해주는 앱. 폰에 설치해두면 코드를 고칠 때마다 실시간으로 반영된다. |
| Expo Router | `app/` 폴더 안의 파일 하나하나가 자동으로 화면(페이지)이 되는 라우팅(화면 이동) 방식. Expo가 공식 추천하는 표준. |
| TypeScript | 타입(값의 종류)을 명시할 수 있는 JavaScript. 실수를 코드 작성 단계에서 미리 잡아준다. |
| 크로스플랫폼 (cross-platform) | 코드 하나로 여러 플랫폼(iOS, 안드로이드 등)에서 동작하게 만드는 방식. |
| 백그라운드 프로세스 / 데몬 (daemon) | 사용자가 직접 보지 않아도 컴퓨터 뒤에서 계속 돌아가는 프로그램. PunchGrow의 사용량 수집기가 이런 형태가 될 예정. |
| PRD (Product Requirements Document) | 제품이 무엇을, 왜 만드는지 정리한 문서. `문서/PRD.md` 참고. |
| ADR / 결정 기록 | 왜 이런 기술적·제품적 결정을 내렸는지 이유를 남기는 짧은 기록. `문서/DECISIONS.md` 참고. |
| 와이어프레임 | 화면의 뼈대(요소 배치)만 간단히 그려본 설계도. 디자인 전에 구조를 먼저 잡는 용도. |
| npm / package.json | JavaScript 라이브러리(패키지)를 관리하는 도구와 그 목록 파일. |
| Claude Code 토큰 | Claude Code가 AI 요청을 처리하면서 사용하는 입력·출력·캐시 단위. PunchGrow 초기 버전의 핵심 활동량 원천이다. 현금이나 Anthropic 결제 잔액을 뜻하지 않는다. |
| PunchGrow 토큰 | 성장과 가챠에 사용하는 단일 수치. Claude Code 실사용량을 중심으로 출석·보상형 광고·운영 보상으로도 무료 획득할 수 있다. 구매·판매·양도·환급할 수 없으며 금전적 가치가 없다. |
| OpenTelemetry (OTel) | 프로그램이 사용량과 성능 같은 숫자 정보를 외부로 전달하는 공개 표준. PunchGrow는 Claude Code가 공식 제공하는 OTel 토큰 메트릭만 받으며 프롬프트나 소스코드를 받을 필요가 없다. |
| PunchGrow 수집기 | Claude Code를 사용하는 PC 또는 Mac에 설치되는 작은 보조 프로그램. 토큰 사용량에서 개인정보를 제거한 뒤 PunchGrow 서버로 전달한다. 모바일 앱만으로는 컴퓨터의 사용량을 직접 읽을 수 없기 때문에 필요하다. |
| iOS Simulator | Mac 안에서 가상의 iPhone을 실행해 앱을 테스트하는 Xcode 도구. 실제 아이폰이나 유료 Apple Developer 계정 없이도 사용할 수 있다. |
| Android Emulator | 컴퓨터 안에서 가상의 Android 휴대폰을 실행하는 Android Studio 도구. 초기 PunchGrow 개발에서는 최신 Pixel 계열 가상 기기 한 대를 사용한다. |
| EAS Build | Expo 서버에서 iOS·Android 설치 파일과 스토어 제출용 빌드를 만드는 서비스. PunchGrow에서는 계정 보유자가 인증 정보를 연결해 TestFlight와 Google Play 빌드를 만드는 핸드오프 경로로 사용한다. |
| TestFlight | Apple이 제공하는 iOS 앱 사전 테스트 배포 서비스. 업로드와 외부 배포에는 유료 Apple Developer Program 계정이 필요하다. |
| PROCESS / AGENT / DAEMON / ORACLE / ARCHITECT / ORIGIN | PunchGrow의 6개 크리처 희귀 등급. 낮은 단계에서 높은 단계 순서이며, 희귀도와 세계 안에서의 존재 권한을 함께 나타낸다. |
| 변이형 | 기본 계열에서 비정상적인 조건으로 갈라져 능력·외형·서사 또는 진화가 달라진 크리처. 별도 도감 항목으로 등록된다. |
| 유니크 컬러 | 기본 크리처와 능력·진화·스토리·도감 슬롯은 같지만 매우 낮은 확률로 다른 색상으로 등장하는 외형 변종. |
| 혼합 진화 | 서로 다른 계열, 속성 또는 재료의 영향을 함께 받아 새로운 계열로 진화하는 방식. 구체적인 조건은 후속 설계에서 확정한다. |
| macOS 메뉴 막대 앱 | Mac 화면 위쪽 메뉴 막대에 작은 아이콘으로 상주하며 눌렀을 때 창이나 메뉴가 열리는 앱. PunchGrow의 1차 오픈소스 제품 형태다. |
| Swift / SwiftUI | Swift는 Apple 플랫폼용 프로그래밍 언어이고 SwiftUI는 화면을 만드는 Apple의 도구다. macOS PunchGrow를 가볍고 시스템 친화적인 네이티브 앱으로 만들 때 사용한다. |
| Homebrew Cask | Mac용 GUI 앱을 터미널 명령으로 설치·업데이트하는 Homebrew 배포 방식. PunchGrow 메뉴 막대 앱은 `brew install --cask` 형태의 설치를 목표로 한다. |
| 로컬 싱글 플레이 | 계정이나 서버 없이 사용자 Mac 안에만 데이터를 저장해 혼자 플레이하는 방식. 메뉴 막대 PunchGrow는 배틀·랭킹·모바일 동기화를 제공하지 않는다. |
| MIT License | 소스 코드를 누구나 사용·수정·재배포·상업 이용할 수 있게 하는 간단한 오픈소스 라이선스. 저작권 고지와 라이선스 문구는 유지해야 한다. |
| CC BY 4.0 | 설정·세계관·일반 문서를 출처 표시 조건으로 수정·재배포·상업 이용할 수 있게 하는 라이선스. PunchGrow 크리처 이미지에는 적용하지 않는다. |
| 권리 유보 | 별도 허락 없이 복제·재배포·상업 이용 등을 허용하지 않는다는 뜻. PunchGrow 크리처 이미지와 파생 시각물에 적용한다. |
| Developer ID 서명 | Mac 앱이 등록된 개발자가 만든 것이며 배포 뒤 변조되지 않았음을 macOS가 확인하게 하는 Apple의 코드 서명 방식. 정식 공개 직전에 유료 개발자 계정으로 적용한다. |
| Apple 공증 (notarization) | Apple이 Mac 앱을 자동 검사하고 안전성 확인표를 발급하는 절차. App Store 심사와는 다르며 Homebrew로 직접 배포할 때 Gatekeeper 경고를 줄이는 데 필요하다. |
| Apple Silicon | M1·M2·M3·M4처럼 Apple이 직접 만든 Mac 프로세서 계열. PunchGrow 메뉴 막대 앱의 첫 버전은 M1 이상만 지원한다. |
| `.pgrow` 백업 파일 | PunchGrow의 토큰·크리처·도감·아이템·진행도를 한 번에 저장해 다른 Mac이나 새 설치에서 복원하는 로컬 세이브 파일. 서버에는 자동 전송되지 않는다. |
| 선택 대기 | 진화 갈림길에서 사용자가 다음 모습을 아직 고르지 않아 성장이 잠시 멈춘 상태. 배지로 표시되며, 도감에서 미리 선호를 정해두면 이 상태를 겪지 않고 지나갈 수 있다. |
| 종착 종 | 그 이후로는 더 진화하지 않는 크리처. 변이형은 모두 종착 종이며, 일반 진화 계보에서도 마지막 단계는 종착 종이다. |
| 변이 재도전 | 이미 다른 길로 진화가 끝나 변이형을 만날 기회를 놓친 크리처를 대상으로, 토큰을 내고 그 계보의 변이형을 새 개체로 다시 노리는 기능. 회당 1,000,000토큰에 성공 확률 10%다. |
| 천장 | 확률형 시도가 계속 실패해도 일정 횟수를 넘기면 다음 시도는 무조건 성공하게 만드는 안전장치. 변이 재도전은 같은 계보에서 30회 연속 실패하면 다음 시도가 확정 성공한다. |
| 계승 | 이미 최종 진화(종착 종)까지 마친 크리처를 기반으로 같은 시작종의 새 개체를 얻어, 이번에는 다른 진화 분기를 다시 키워볼 수 있게 하는 기능. 5,000,000토큰이 든다. |
| 만렙 축전 | 크리처가 만렙(Lv.50)에 도달한 것을 축하하는 표시. 도달하는 순간 금색 LEVEL MAX 알림이 한 번 뜨고, 이후에는 메인 화면 카드의 테두리와 레벨 게이지가 금색으로 남아 성장이 완성됐음을 보여준다. 능력치가 좋아지는 것은 아니다. |
| 최대 도달 등급 | 지금 고를 수 있는 진화 분기 중 가장 좋은 선택을 계속했을 때 최종적으로 도달할 수 있는 가장 높은 등급. 확률로만 만나는 변이는 포함하지 않으며, 실제로 그 등급에 이르렀다는 뜻이 아니라 "이 계보에서 고를 수 있는 최선의 결과"를 보여주는 값이다. |
