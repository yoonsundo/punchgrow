# PunchGrow 제품 문서 안내

이 폴더는 “무엇을 만들기로 했는지”와 “왜 그렇게 정했는지”를 기록하는 한국어 제품 문서 공간입니다. 설치·사용법처럼 외부 사용자가 바로 읽어야 하는 문서는 [`docs/`](../docs/README.md)에 있습니다.

## 먼저 읽을 문서

1. [`PRD.md`](PRD.md) — 현재 확정된 제품 스펙
2. [`DECISIONS.md`](DECISIONS.md) — 비자명한 결정과 이유
3. [`GLOSSARY.md`](GLOSSARY.md) — 초보자 눈높이의 용어 설명
4. [`IMPLEMENTATION_STATUS.md`](IMPLEMENTATION_STATUS.md) — 현재 실행 가능한 범위와 남은 제약
5. [`WIREFRAMES.md`](WIREFRAMES.md) — 화면 구조와 라우팅 맵

## 크리처 디자인 자료

- [`CREATURE_DESIGN_BIBLE.md`](CREATURE_DESIGN_BIBLE.md) — 공통 시각 원칙과 승인 기준
- [`CREATURE_REPRESENTATIVE_SIX_PACKAGES.md`](CREATURE_REPRESENTATIVE_SIX_PACKAGES.md) — 대표 6계열 제작 패키지
- [`CREATURE_LINEAGE_001_EILU.md`](CREATURE_LINEAGE_001_EILU.md) — 에일루 계열의 상세 기준
- [`ELEMENTAL_ORIGINS.md`](ELEMENTAL_ORIGINS.md) — 원초 ORIGIN 4원소 콘셉트

## 갱신 원칙

- 확정된 제품 동작이 바뀌면 `PRD.md`를 함께 갱신합니다.
- 새로운 구조·정책처럼 이유가 필요한 결정은 `DECISIONS.md`에 기록합니다.
- 구현 현황은 완료를 과장하지 않고 검증된 사실과 남은 차단점을 구분합니다.
- 외부 사용법과 저장소 구조는 각각 `docs/USAGE*.md`, [`docs/PROJECT_STRUCTURE.md`](../docs/PROJECT_STRUCTURE.md)에 둡니다.
