# PG-L001 — 에일루 계열

## 승인 상태

- 상태: 대표 PROCESS 계열 승인
- 계열 ID: `PG-L001`
- 형태: 여우형 네발짐승
- 진화 단계: 3단계
- 핵심 주제: 버려진 가능성이 성장해 수많은 길을 통제하는 존재가 된다.

## 단계

### 1단계 — 에일루 / Eilu

- 등급: PROCESS
- 성격: 호기심이 많고 사용자의 작업을 따라다닌다.
- 역할: 처리되지 못한 작은 명령 조각을 꼬리 코어에 모은다.
- 행동 특징: 사용자가 집중하면 꼬리의 빛 가지가 조용히 늘어난다.
- 형태 DNA: 큰 직립 귀, 청록색 눈과 이마 문양, 크림색 볼·가슴 털, 다면체 꼬리 코어, 가지형 빛 경로

### 2단계 — 에일반 / Eilvan

- 등급: AGENT
- 성격: 민첩하고 판단이 빠르며 위험한 경로를 먼저 확인한다.
- 역할: 여러 실행 경로를 동시에 탐색해 실패 가능성이 낮은 길을 선택한다.
- 행동 특징: 다이아몬드 코어와 궤도 고리가 회전하며 선택 가능한 경로를 정렬한다.
- 형태 변화: 길고 낮은 질주 자세, 분기된 신호형 귀, 유기 외골격 어깨, 두 갈래 제어 경로

### 3단계 — 에일시온 / Eilsion

- 등급: DAEMON
- 성격: 침착하고 위엄 있으며 불필요한 움직임이 없다.
- 역할: 수많은 작업 경로가 충돌하지 않도록 전체 흐름을 통제한다.
- 행동 특징: 거대한 다면체 코어가 주변 공간의 실행 순서를 재구성한다.
- 형태 변화: 긴 신호탑형 귀, 웅장한 직립 자세, 통합 금속 외골격, 구형 명령 코어와 질서 있는 빛 경로

## 기원과 진화 서사

실행되지 못하고 사라진 작은 명령 조각들이 사용자의 꾸준한 개발 활동에 반응해 에일루로 태어난다. 경험이 쌓이면 가능성만 수집하던 존재에서 직접 경로를 탐색하는 에일반으로 성장한다. 최종적으로 수많은 선택과 실패를 하나의 질서로 묶는 에일시온이 된다.

- 보조색: 페일 크림
- 발광 강조색: 시안
- 초기 재질: 유기적인 짧은 털

- 에일루의 큰 귀, 청록 눈, 이마 문양과 크림색 볼·가슴 털
- 하나의 해부학적 꼬리에서 이어지는 다면체 코어
