# PunchGrow 크리처 디자인 바이블

## 2026-08 전면 리디자인 기준 — Cute Clarity v2

사용자 검토에서 상위 등급이 장식과 부속물 때문에 난잡하다는 문제가 확인되었다. v2의 기준은 **에일루처럼 한눈에 읽히는 실루엣 + 모든 등급의 귀여운 감정 접점 + 장식 대신 자세와 크기감으로 표현하는 위엄**이다.

- 색은 주색 1, 보조색 1, 발광색 1로 제한한다.
- 대표기관은 정확히 1개, 보조기관은 최대 1개다.
- 96px에서 보이는 실루엣 덩어리는 3~5개여야 한다.
- 얼굴은 전체 높이의 최소 15%이며, 큰 홍채·짧은 주둥이·둥근 이마·명확한 표정 중 최소 2개를 사용한다.
- 다중 광륜, 부유 장신구, 반복 룬, 회로 도배, 작은 얼굴, 과도한 갑옷과 가시는 금지한다.
- 강함은 부품 수가 아니라 체형, 자세, 크기 대비, 빈 공간, 하나의 거대한 대표기관으로 표현한다.
- 96px 흑색 실루엣, 128px 얼굴 인지, 등급 접촉표 테스트를 모두 통과해야 승인한다.
- 기존 이미지는 `legacy-v1`로 보존한다. `cute-redesign-v2`는 240종 마스터·360px 모바일 파생본 제작과 시각 QA를 마쳐 2026-08-02 개발본의 활성 팩으로 전환했다.
- API 키 없는 Codex 구독 제작에서는 투명 배경을 요구하지 않는다. 모든 정식 v2 이미지는 `#08111F` 짙은 남색 정사각 카드 배경과 개체 고유색의 약한 중앙 방사광을 사용한다.
- 배경에는 장면, 바닥, 그림자, 입자, 문자, 로고, 워터마크를 넣지 않는다. 개체는 카드 면적의 최소 70%를 차지하고 8~10% 안전 여백을 둔다.
- 대표 6종은 Visual Ralph 승인 후 240종 제작의 고정 기준 세트로 사용했으며, 최종 240종도 90점 이상 게이트를 통과했다.

| 등급 | 귀여운 핵심 | 위엄 표현 | 허용 특수 요소 |
|---|---|---|---|
| PROCESS | 큰 머리, 호기심 표정 | 탄력 있는 자세 | 작은 대표기관 1 |
| AGENT | 둥근 얼굴, 집중된 큰 눈 | 전진·상승 대각선 | 대표기관 1 + 보조 1 |
| DAEMON | 친근한 눈, 둥근 전면 | 낮고 넓은 안정 자세 | 대형 보호기관 1 |
| ORACLE | 큰 얼굴핵, 조용한 미소 | 작은 몸과 큰 빈 공간 대비 | 대형 광륜 1 |
| ARCHITECT | 읽기 쉬운 눈, 반응하는 더듬이 | 굵은 몸통과 정밀한 대칭 | 도구기관 1 + 날개판 1쌍 |
| ORIGIN | 큰 차분한 눈, 짧은 입선 | 거대 날개, 낮춘 머리, 넓은 여백 | 왕관 또는 거대 날개 1 |

## 목적

이 문서는 Google Antigravity에서 PunchGrow 크리처를 제작할 때 사용하는 시각 디자인 정본이다. 여러 번 생성하고 여러 사람이 작업해도 240종이 같은 디지털 신화 세계에 속하면서 서로 다른 계열로 식별되게 한다.

## 전체 스타일

- 선명한 외곽 실루엣의 2D 셀 셰이딩
- 내부에는 제한적인 부드러운 입체 명암
- 작은 메뉴 막대와 도감 썸네일에서도 얼굴과 핵심 특징이 보여야 함
- 초기형은 친근하고 생명감 있게, 진화할수록 신성하고 기계적인 위압감 강화
- 사진 같은 사실주의, 납작한 유아 카툰, 고어, 혐오와 신체 공포 금지
- 특정 유명 몬스터 IP의 얼굴, 실루엣, 색 배치와 대표 장식 복제 금지

## 로스터 감성 비율

시작 계열 60종을 다음 비율로 구성한다.

- 귀여운 계열: 50%
- 귀여움과 강함이 섞인 균형형: 30%
- 처음부터 강인한 계열: 20%

진화할수록 강인하고 신성한 인상이 늘어난다. 단, ORACLE·ARCHITECT급 일부는 작고 귀여운 외형을 유지하면서 공간 왜곡, 부유 구조, 강한 광원과 침착한 자세로 힘을 표현한다.

## 신체 형태

- 네발짐승
- 두발짐승
- 조류
- 수생형
- 부유 정령형
- 곤충·기계구조체
- 기타 무정형·식물형은 전체 확장 단계에서 추가 가능

사람과 거의 같은 인간형은 소수만 사용한다. 초기형은 큰 머리와 눈, 짧은 몸과 팔다리로 친근함을 만든다. 진화할수록 머리 비율을 줄이고 몸, 팔다리, 날개와 장갑 구조를 길고 웅장하게 확장한다.

## 생물과 디지털 재질

- 초기: 털, 피부, 비늘, 껍질 등 유기 재질 중심
- 중간: 피부 아래 발광 회로와 작은 외골격 출현
- 고단계: 금속 외골격, 투명 에너지 기관과 부유 구조가 신체 일부로 성장

단순히 갑옷이나 기계를 착용한 모습보다 골격과 기관이 자연스럽게 변형된 모습을 우선한다.

## 공통 디지털 신화 문법

1. 부유하는 고리
2. 다각형 신화문자
3. 몸을 흐르는 발광 회로

각 크리처에는 최소 하나를 사용한다. 한 개체에는 최대 두 범주만 사용하며, 각 계열은 대표 요소 하나를 형태 DNA로 고정한다. 세 요소를 모두 붙여 획일화하는 것을 금지한다.

## 진화 연속성

진화 전후에는 다음 중 최소 두 가지를 유지한다.

- 귀·뿔·볏의 외곽선
- 꼬리·날개·지느러미 구조
- 눈 모양과 얼굴 표식
- 대표 회로 또는 신화문자
- 계열 고유 팔레트
- 몸통과 다리의 핵심 비율 리듬

변이형은 색상만 바꾸지 않는다. 실루엣, 기관, 재질 중 두 항목 이상이 달라야 한다.

## 색상

- 계열마다 주색 1, 보조색 1, 발광 강조색 1
- 각 단계의 주색·보조색·발광색은 실제 승인 이미지에서 충분한 면적으로 확인되는 색을 기록한다. 같은 계열의 발광색은 인접 단계 RGB 거리 120 이하의 계통을 유지하고, 형태 DNA 2개 이상과 공통 디지털 모티프로 계열 연속성을 보존한다.
- 등급별 고정 색상 금지
- 고등급은 제한된 발광 강도, 재질, 자세, 크기 대비와 하나의 대표기관으로 구분
- 유니크 컬러는 구조와 능력을 유지한 별도 팔레트
- 다크 UI 대비와 색각 접근성 검사 필수

## 이름

- 2~4음절 중심의 독자 고유명
- 한국어와 로마자 영문 표기를 함께 기록
- 원전 신화의 고유명 직접 사용 금지
- 기술 명령어와 흔한 판타지 합성어 직접 사용 금지
- 같은 진화 계열은 음절, 리듬, 어근 중 하나를 공유

## 대표 6계열

| 대표 등급 | 형태 | 역할 | 형태 DNA | 공통 요소 |
|---|---|---|---|---|
| PROCESS | 여우형 네발 | 귀엽고 민첩한 안내자 | 큰 귀, 분할된 빛 꼬리, 가벼운 발 | 발광 회로 |
| AGENT | 조류형 | 탐색과 전달을 맡는 정찰자 | 꺾인 날개 끝, 눈 표식, 꼬리깃 | 다각형 신화문자 |
| DAEMON | 수생형 | 깊은 흐름을 지키는 수호자 | 유선형 등선, 측면 지느러미, 발광 아가미 | 발광 회로 |
| ORACLE | 부유 정령형 | 작고 귀엽지만 미래 경로를 읽는 관측자 | 둥근 핵, 짧은 촉수, 분리된 손 | 부유 고리 |
| ARCHITECT | 곤충 기계형 | 세계 구조를 조립하는 건축자 | 분절 외골격, 대칭 날개판, 도구형 앞다리 | 문자와 회로 |
| ORIGIN | 거대 용형 | 최초 규칙을 체현한 존재 | 긴 목선, 거대한 문날개 1쌍, 짧은 관뿔 | 고리와 문자 |

이 표의 역할명은 제작용 설명이다. 최종 고유명은 후보 생성과 유사성 검토 후 결정한다.

## 계열별 Antigravity 작업 패키지

각 계열은 다음 자료를 모두 포함한다.

1. 한 줄 정체성
2. 기원, 성격, 욕망, 갈등과 진화 서사
3. 단계별 유지 DNA와 변화 항목
4. 정면·측면·후면 삼면도
5. 단계별 크기 비교와 대표 포즈
6. 주색·보조색·발광색과 재질 견본
7. 중립·기쁨·배고픔·수면·놀람·분노 표정
8. 대기·호흡·기쁨·먹기·수면·공격·피격·진화 모션 키포즈
9. 변이형 1안과 유니크 컬러 2안
10. `#08111F` 카드 배경 전신, 메뉴 막대 축소와 도감 썸네일 시험
11. 금지 요소와 타 IP 비유사성 검토표

## Antigravity 프롬프트 순서

항상 다음 순서를 유지한다.

`세계관 역할 → 신체 형태 → 단계와 비율 → 형태 DNA → 유기 재질 → 디지털 기관 → 팔레트 → 표정과 포즈 → 2D 셀 셰이딩 → 카메라와 배경 → 금지 요소`

한 번에 여러 진화 단계를 생성하지 않는다. 초기형 승인 후 그 이미지를 다음 단계의 참조로 고정한다. 전신 시안 승인 후 삼면도와 표정 시트를 별도로 만든다.

## 납품 규격

- `#08111F` 카드 배경 PNG, 정사각형 최소 1024×1024
- 레이어 분리 원본 또는 편집 가능한 동등 형식
- sRGB 색공간
- 전신이 잘리지 않고 충분한 투명 여백 포함
- 파일명: `PG_{lineageId}_{stage}_{view}_{variant}_v###`
- 프롬프트, 참조 이미지, 생성일, 버전과 승인 상태 기록

## 승인 체크리스트

- [ ] 검은 실루엣만으로 계열과 단계가 구분된다.
- [ ] 진화 전후에 형태 DNA가 두 가지 이상 유지된다.
- [ ] 메뉴 막대 크기에서 얼굴과 핵심 특징을 알아볼 수 있다.
- [ ] 다른 대표 계열과 실루엣·팔레트가 겹치지 않는다.
- [ ] 공통 디지털 요소가 최대 두 범주를 넘지 않는다.
- [ ] 고등급은 체구와 무관하게 강함과 권위가 느껴진다.
- [ ] 변이형은 색상 변경만으로 만들어지지 않았다.
- [ ] 유니크 컬러가 다크 UI와 색각 접근성 검사를 통과했다.
- [ ] 타 IP 비유사성 검토를 통과했다.
- [ ] 삼면도·진화·색상·표정·모션·축소 시험이 모두 승인됐다.

대표 6계열의 기본 전신·축소 가독성·형태 DNA를 먼저 승인한 뒤 같은 규격으로 240종을 완성했다. 삼면도·표정·모션·변형 제작 규격은 상세 작업 패키지로 유지하고, 실제 시트는 앱에서 해당 계열을 애니메이션하는 단계에 제작·승인한다.

## 대표 제작 계열

아래 항목은 등급별 제작 기준 계열이다. `cute-redesign-v2` 대표 여섯 종은 고정 앵커이며 활성 240종 팩의 시각 기준이다.

- `PG-L001 에일루 → 에일반 → 에일시온`: PROCESS 대표 여우형 3단계 계열. 상세 정본은 `문서/CREATURE_LINEAGE_001_EILU.md`를 따른다.
- `PG-102 리토니온`: AGENT 대표 조류형. 낫형 날개끝, 이마 눈형 문양, 두 가닥 꼬리깃을 기준으로 한다.
- `PG-109 마젤론라크`: DAEMON 대표 수생형. 유선형 등선, 측면 지느러미, 발광 아가미를 기준으로 한다.
- `PG-193 퀴논`: ORACLE 대표 부유 정령형. 점핵, 짧은 촉수, 분리된 손기관과 대형 고리를 기준으로 한다.
- `PG-166 자르펜라크`: ARCHITECT 대표 곤충 기계형. 분절 외골격, 대칭 날개판, 도구형 앞다리를 기준으로 한다.
- `PG-211 피티온`: ORIGIN 대표 거대 용형. 긴 목선, 거대한 문날개 1쌍, 짧은 관뿔을 기준으로 한다.
- 여섯 대표의 제작 프롬프트·삼면도·표정·모션·변형·축소 규격은 `문서/CREATURE_REPRESENTATIVE_SIX_PACKAGES.md`를 따른다.
