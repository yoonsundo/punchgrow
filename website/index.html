01 / THE LOOP

코딩한 만큼,
세계가 자란다.

사용량 숫자는 토큰이 되고, 토큰은 수집과 성장의 선택지가 됩니다. 모든 개체는 작은 PROCESS에서 시작합니다.

  1. 01

    CODE

    Claude Code와 Codex의 로컬 사용량 증가분을 읽습니다.

  2. 02

    COLLECT

    쌓인 토큰으로 64개 시작 계보를 발견합니다.

  3. 03

    GROW

    먹이와 선택으로 크리처를 성장시키고 진화시킵니다.

  4. 04

    EXPAND

    분기와 변이를 따라 256종 도감을 완성해 갑니다.

03 / PRIVACY BY DESIGN

숫자만 읽고,
내용은 읽지 않습니다.

PunchGrow는 로컬에서 실행됩니다. 수집은 명시적으로 켜야 시작되며, 프롬프트와 응답, 소스 코드, 명령어, 프로젝트명, 계정 정보는 게임 데이터에 저장하거나 전송하지 않습니다.

05 / INSTALL

당신의 Mac에서
직접 시작하세요.

Apple Silicon Mac과 macOS 14 이상이 필요합니다. Homebrew v0.4.0 릴리스와 현재 main 소스·공개 도감에는 모두 64개 시작 계보·256종이 있습니다.

HOMEBREW / v0.4.0 · 256 CREATURES
brew tap yoonsundo/punchgrow https://github.com/yoonsundo/punchgrow
brew trust yoonsundo/punchgrow
brew install --cask punchgrow
xattr -d com.apple.quarantine /Applications/PunchGrow.app

2026-08-18 배포본은 64개 시작 계보·256종과 ORIGIN 도달 계보 7/64(약 10.9%)를 포함합니다. ad-hoc 서명 빌드라 첫 실행 전에 격리 속성을 제거하고, Homebrew 6 미만에서는 brew trust를 건너뛰세요.

SOURCE BUILD / CURRENT MAIN · 256 CREATURES
git clone https://github.com/yoonsundo/punchgrow.git
cd punchgrow/macos
./scripts/build-app.sh
open .build/PunchGrow.app

추가 16종을 포함한 현재 개발본이며 Full Xcode가 필요합니다. 자세한 설치·삭제·문제 해결은 사용 가이드에서 확인하세요.
