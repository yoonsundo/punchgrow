01 / THE LOOP

코딩한 만큼,
세계가 자란다.

사용량 숫자는 토큰이 되고, 토큰은 수집과 성장의 선택지가 됩니다. 모든 개체는 작은 PROCESS에서 시작합니다.

  1. 01

    CODE

    Claude Code와 Codex의 로컬 사용량 증가분을 읽습니다.

  2. 02

    COLLECT

    쌓인 토큰으로 64개 시작 계보를 발견합니다.

  3. 03

    GROW

    먹이와 선택으로 크리처를 성장시키고 진화시킵니다.

  4. 04

    EXPAND

    분기와 변이를 따라 256종 도감을 완성해 갑니다.

03 / PRIVACY BY DESIGN

숫자만 읽고,
내용은 읽지 않습니다.

PunchGrow는 로컬에서 실행됩니다. 수집은 명시적으로 켜야 시작되며, 프롬프트와 응답, 소스 코드, 명령어, 프로젝트명, 계정 정보는 게임 데이터에 저장하거나 전송하지 않습니다.

04 / BUILD FROM SOURCE

당신의 Mac에서
직접 시작하세요.

현재 공개 설치는 소스 빌드 경로를 안내합니다. Apple Silicon Mac, macOS 14 이상, Full Xcode가 필요합니다.

GitHub 저장소 ↗ 사용 가이드 ↗
SOURCE BUILD
# 저장소를 내려받고 앱 빌드
git clone https://github.com/yoonsundo/punchgrow.git
cd punchgrow/macos
./scripts/build-app.sh
open .build/PunchGrow.app

로컬 실행용 ad-hoc 서명 빌드입니다. Developer ID 서명 및 Apple 공증을 마친 공개 바이너리는 아직 안내하지 않습니다.
