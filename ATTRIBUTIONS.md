# Attributions

## PokeTokenBar

PunchGrow's automatic local Claude Code and Codex usage discovery was inspired
by the local-log collection pattern in
[chattymin/PokeTokenBar](https://github.com/chattymin/PokeTokenBar), distributed
under the MIT License.

PunchGrow uses an independent implementation with privacy-safe hashed cache
keys, a no-windfall first-run baseline, and PunchGrow's own Digital Myth Signal
Core interface. No Pokémon names, sprites, artwork, or other third-party visual
assets are included.
