# Biological Continuity v3 staging

This tree is deliberately disconnected from the active creature pack.

- `workspace-masters/` preserves the exact bytes returned by the local built-in ImageGen tool.
- `candidates/` contains a candidate master copy, immutable prompt, deterministic 360×360 runtime derivative, and provenance.
- `approved/` is written only by the finalizer after the complete signed G003 gate passes.
- `rejected/` is append-only evidence. Rejecting a candidate never deletes its private `.omx` reviewer package.

Nothing in this tree is deployed until `biological-continuity-v3` is explicitly registered and activated by a separate operation.
