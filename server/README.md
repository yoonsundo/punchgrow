# PunchGrow Web API

웹 MVP용 PostgreSQL API입니다. 기본적으로 `127.0.0.1`에만 열리며, 서명된 로컬 익명 세션을 사용합니다. 실제 외부 인증은 아직 없으므로 `AUTH_MODE=local`만 허용하며 인터넷에 직접 공개하면 안 됩니다.

`POST /api/token-ingestions`는 `COLLECTOR_SECRET`을 설정한 경우에만 활성화됩니다. 비밀값은 32바이트 이상이어야 하며, 사람이 만든 반복 문자열 대신 `openssl rand -base64 32`처럼 암호학적으로 안전한 난수 생성기로 만드세요. 브라우저용 개발 프록시는 이 수집기 비밀값을 전달하지 않으므로 수집기는 API에 직접 연결해야 합니다.

API의 기본 `HOST`는 `127.0.0.1`입니다. Docker Compose는 컨테이너 안에서 `HOST=0.0.0.0`을 명시하지만 호스트 포트는 계속 `127.0.0.1:4001`에만 게시합니다.

## 게임 규칙

- 가챠 비용: 500,000 토큰
- 가챠 풀: 현재 도감 256종 전체에서 먼저 등급을 추첨하고, 해당 등급의 크리처를 균등 추첨합니다. 시작형 64종만 사용하면 전부 `PROCESS`라 현재 확정된 6단계 확률을 표현할 수 없기 때문입니다.
- 천장: ORIGIN을 300회 연속 얻지 못하면 그 다음(301번째) 요청에서 ORIGIN 확정
- 유니크 컬러: 등급과 별도로 0.1%, 천장 없음
- 신규 로컬 플레이어 개발 잔액: 3,000,000 토큰, 먹이 3개

## 개인정보 경계

`POST /api/token-ingestions`는 UUID 이벤트 ID, `claude_code | codex`, 발생 시각, 입력·출력·캐시 읽기·캐시 쓰기 토큰 정수만 허용합니다. 프롬프트, 응답, 파일 경로, 명령, 이메일 또는 계정 식별자 필드는 거부합니다. 이벤트 ID는 플레이어별 고유하며 재전송은 잔액을 다시 지급하지 않습니다.
