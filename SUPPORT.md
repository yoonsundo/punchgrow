# Support / 사용 도움

[한국어](#한국어) · [English](#english)

## 한국어

먼저 [사용 가이드](docs/USAGE.md)의 설치·문제 해결 항목과 [기여 가이드](CONTRIBUTING.md)를 확인해 주세요.

- 재현 가능한 버그: [버그 이슈 작성](https://github.com/yoonsundo/punchgrow/issues/new?template=bug_report.yml)
- 작고 구체적인 개선 제안: [기능 이슈 작성](https://github.com/yoonsundo/punchgrow/issues/new?template=feature_request.yml)
- 보안·개인정보 문제: 공개 이슈를 만들지 말고 [보안 정책](SECURITY.md)을 따라 주세요.

이슈에는 PunchGrow 버전, macOS·하드웨어 환경, 재현 순서, 실제 결과와 기대 결과를 적어 주세요. 로그와 화면 캡처에서는 비공개 프롬프트·응답·소스 코드, 명령어에 포함된 비밀값, 개인을 식별할 수 있는 경로·이메일·계정 정보를 제거하거나 가려 주세요. 재현에 필요한 공개 코드·명령어와 정제한 경로 예시는 포함해도 됩니다.

## English

Start with the installation and troubleshooting sections in the [user guide](docs/USAGE.en.md) and the [contributing guide](CONTRIBUTING.en.md).

- Reproducible bug: [open a bug report](https://github.com/yoonsundo/punchgrow/issues/new?template=bug_report.yml)
- Focused improvement: [open a feature request](https://github.com/yoonsundo/punchgrow/issues/new?template=feature_request.yml)
- Security or privacy concern: do not open a public issue; follow the [security policy](SECURITY.md).

Include the PunchGrow version, macOS and hardware environment, reproduction steps, actual behavior, and expected behavior. Remove or mask private prompts, responses, non-public source code, secrets embedded in commands, identifying paths, email addresses, and account details from logs and screenshots. Sanitized code, commands, and path examples needed to reproduce the issue are welcome.
